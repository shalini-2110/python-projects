# Hostel Room Allocation System

A Python program that automatically allocates students to hostel rooms, 
prevents over-allocation, displays occupancy, and generates a hostel receipt.

## Features
- 5 rooms, capacity 2 students each (max 10 total)
- Auto-allocates to the first available room
- Prevents allocation once all rooms are full
- Displays room occupancy before each allocation
- Generates a hostel fee receipt (₹8000/student)

## How to run
```bash
python hostel-allocation.py
```

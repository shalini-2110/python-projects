# Vehicle Service Billing System

A Python program that calculates a vehicle service invoice based on 
selected service package, spare parts cost, and GST, with an estimated 
delivery day.

## Features
- Service packages: Basic (₹1500), Standard (₹3000), Premium (₹5000)
- Spare parts cost (user input)
- GST: 18% on (service charge + spare parts cost)
- Estimated delivery: service start day + 3 days
- Generates a detailed invoice

## How to run
```bash
python vehicle-service.py
```

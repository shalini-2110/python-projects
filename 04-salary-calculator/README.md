# Employee Salary Calculator

A Python program that calculates gross salary, deductions (PF, professional tax, 
income tax), net salary, and annual salary from a given basic salary.

## Features
- DA (10% of Basic) and HRA (20% of Basic)
- Gross Salary = Basic + DA + HRA
- PF (12% of Basic), Professional Tax (₹200 flat), Income Tax (5% of Gross)
- Net Salary = Gross − Total Deductions
- Annual Salary = Net Salary × 12
- Prints a formatted salary slip

## How to run
```bash
python salary-calculator.py
```

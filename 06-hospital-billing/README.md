# Hospital Patient Billing System

A Python program that generates a patient invoice based on patient type, 
medicine charges, lab charges, and insurance discount.

## Features
- Auto-generated Patient ID
- Consultation fee: ₹500 (General) or ₹1000 (VIP)
- Medicine and lab charges (user input)
- 20% insurance discount (if applicable)
- Prints a detailed final invoice

## How to run
```bash
python hospital-billing.py
```

# Student Marks Management System

A Python program that calculates a student's total, average (ignoring lowest mark), 
highest/lowest marks, grade, and class rank. Supports multiple students.

## Features
- 6 subjects per student
- Average calculated by ignoring the lowest mark
- Grading: A(90+), B(80+), C(70+), D(60+), E(35+), F(below 35)
- Rank: Distinction(75+), First Class(60+), Second Class(50+), Pass(35+), Fail(below 35)
- Stores multiple students in a list

## How to run
```bash
python student-marks.py
```

# Complaint Management System

A Python program where users register complaints with a priority level, 
and admins can search by Complaint ID to update status and resolution date.

## Features
- Auto-generated Complaint ID
- Priority levels: Low/Medium/High
- Case-insensitive search by Complaint ID
- Status update (Pending/In Progress/Resolved)
- Records resolution date when resolved

## How to run
```bash
python complaint-system.py
```

# Electricity Bill Calculator

A Python program that calculates electricity bills using slab-wise rates, 
a fixed meter charge, GST, and a late payment penalty.

## Features
- Slab rates: ₹3/unit (0-100), ₹5/unit (101-200), ₹7/unit (200+)
- Fixed meter charge: ₹50
- GST: 18% on (energy charge + meter charge)
- Late payment penalty: ₹100 flat
- Prints a detailed final bill

## How to run
```bash
python electricity-bill.py
```

# Quiz / MCQ Evaluator

A Python program that displays multiple-choice questions in random order, 
evaluates answers, calculates score and percentage, and reveals correct 
answers for any wrong responses.

## Features
- 5 questions, 2 marks each (Total: 10 marks)
- Questions shuffled randomly each run
- Score and percentage calculation
- Shows correct answers for wrong responses

## How to run
```bash
python quiz-evaluator.py
```

# Membership Fee Calculator

A Python program that calculates membership fees based on plan type, 
applies student discounts, and determines the expiry month.

## Features
- Plans: Monthly (₹500), Quarterly (₹1300), Yearly (₹4800)
- 10% student discount (if applicable)
- Auto-generated Membership ID
- Calculates expiry month based on joining month + plan duration
- Prints a membership receipt

## How to run
```bash
python membership-calculator.py
```

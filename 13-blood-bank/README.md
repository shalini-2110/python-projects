# Blood Bank Management System

A Python program that tracks blood stock by group, allows donations, 
supports searching stock by blood group, and alerts on low stock.

## Features
- Tracks stock for 8 blood groups
- Case-insensitive blood group input
- Donate blood (adds to stock, generates receipt)
- Search stock by blood group
- Low-stock alert when units fall below 3

## How to run
```bash
python blood-bank.py
```

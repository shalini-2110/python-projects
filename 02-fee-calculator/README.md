# Fee Calculator

A Python program that calculates total fees (tuition, lab, bus, hostel), 
applies a scholarship discount, adds a late fee if applicable, and 
generates a receipt with a unique receipt number.

## Features
- Fixed fees: Tuition (₹1400), Lab (₹7000), Bus (₹20000), Hostel (₹8000)
- 15% scholarship discount (if applicable)
- ₹100 flat late fee (if payment is late)
- Auto-generated receipt number
- Final itemized receipt printout

## How to run
```bash
python fee-calculator.py
```

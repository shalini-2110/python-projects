# Library Book Issue & Fine System

A Python program that issues books to students, tracks days taken to return, 
calculates overdue fines, and prevents duplicate book issues.

## Features
- Maximum 3 books per student
- Due period: 7 days
- Fine: ₹2/day after due period
- Prevents issuing the same book twice to a student
- Displays total fine summary

## How to run
```bash
python library-system.py
```

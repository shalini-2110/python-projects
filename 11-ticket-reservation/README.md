# Ticket Reservation System

A Python program that manages seat reservations, calculates fare by distance, 
and prevents double booking of the same seat.

## Features
- 10 seats, tracked with availability status
- Fare: ₹5/km
- Auto-generated ticket number
- Prevents booking an already-booked seat
- Displays seat availability before each booking

## How to run
```bash
python ticket-reservation.py
```

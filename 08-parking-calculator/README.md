# Parking Fee Calculator

A Python program that calculates parking charges based on vehicle type 
and duration, and generates a parking token with receipt details.

## Features
- Rates: Bike (₹10/hr), Car (₹20/hr), Bus (₹50/hr)
- Auto-generated parking token
- Displays entry time and hours parked
- Prints a detailed parking receipt

## How to run
```bash
python parking-calculator.py
```

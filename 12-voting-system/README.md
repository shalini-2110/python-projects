# Voting System

A Python program that lets eligible voters (18+) cast a single vote for a 
candidate, prevents duplicate voting, and displays election results.

## Features
- Age validation (must be 18+)
- Prevents the same person from voting twice
- Auto-generated Voter ID
- Automatic vote counting per candidate
- Displays final results and the winner

## How to run
```bash
python voting-system.py
```
